# Текущий план — AppRoute VPN

Обновлено: 2026-10-22.

## Цель

Рабочая Linux-утилита для запуска выбранных приложений через WireGuard без переключения всей системы на VPN.

## Выполнено

- CLI `up`, `run`, `status`, `down`.
- Отдельное сетевое пространство и DNS для запускаемых программ.
- Разбор конфигурации, отказ от hooks, очистка ресурсов при ошибке настройки.
- Запуск приложений от обычного пользователя, проверка процессов перед отключением.
- Пять модульных тестов.
- README и база знаний `kb/`.

## Текущий этап

MVP реализован; интеграционное подтверждение на реальном VPN ещё не выполнено. Создание документации не меняет этот статус.

## Следующие действия

1. Установить системные зависимости на тестовой Linux-машине.
2. Подключить действительный WireGuard-конфиг, выполнить [ручные проверки](kb/tests.md).
3. Зафиксировать результаты и обнаруженные ограничения в `kb/progress.md` и `kb/tests.md`.
4. После проверки выбрать следующий этап из [roadmap](kb/roadmap.md).

## Правило сопровождения

При изменении поведения или команд всегда обновлять соответствующие документы в `kb/`, при необходимости README и этот план. Навигация: [kb/index.md](kb/index.md).
