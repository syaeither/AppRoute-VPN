# Roadmap

Это направления развития, а не уже доступные возможности.

## Этап 1 — подтверждение MVP

Выполнить ручные проверки реального WireGuard, DNS, IPv4/IPv6, обрыва сервера, отключения и повторного подключения. Критерий завершения: записанные результаты и устранённые блокирующие ошибки.

## Этап 2 — надёжность CLI

Проверить конкурентные операции, все этапы отката и восстановление после аварии. Уточнить проверки конфигурации и диагностику состояния. Добавлять тесты для подтверждённых рисков и исправлений.

## Этап 3 — удобство

Профили VPN, сохранённые команды приложений, отдельные профили браузеров, затем GUI. Перед разработкой определить UX и правила хранения конфигураций.

## Этап 4 — расширение архитектуры

Оценить SOCKS/TUN-backend и правила выбора приложений. Windows WFP/драйвер — отдельное исследование и отдельная реализация; текущий Python CLI на Windows не переносится простым запуском.
