# Git и хранение проекта

На момент проверки 2026-10-22 команда `git status --short` из папки проекта завершилась сообщением `not a git repository`. Коммиты, ветки, remote и CI не настроены и не подтверждены. Создание документации не инициализирует Git и ничего не публикует.

## При последующем включении Git

- Согласовать место хранения и remote; отдельно инициализировать репозиторий.
- Хранить исходники, тесты, README, current_plan.md и kb/ вместе.
- При изменении поведения или команд включать обновления kb/ в тот же коммит.
- Перед коммитом запускать модульные тесты и проверять состав изменений.
- Не добавлять приватные ключи, действительные VPN-конфиги, временные файлы или секреты в документации.

В `.gitignore` уже исключены `*.conf`, кэш Python, `.venv/`, метаданные и каталоги сборки. Игнорирование файлов не заменяет проверку изменений перед публикацией.
