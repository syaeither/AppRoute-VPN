# Устройство проекта

## Компоненты

- `approute/__main__.py` — вход для `python3 -m approute`.
- `approute/cli.py` — аргументы CLI, конфигурация, системные команды и обработка ошибок.
- `tests/test_config.py` — модульные проверки парсера и одного пути отката.
- `pyproject.toml` — пакет Python 3.10+ и точка входа `approute`.

## Поток трафика

Приложение → WireGuard `arwg0` внутри `approute-vpn` → зашифрованный UDP через сеть хоста → VPN-сервер → целевой сервис.

Обычные приложения остаются в сети хоста. В namespace доступны loopback и WireGuard; физический сетевой интерфейс туда не переносится.

## Жизненный цикл

`up`: прочитать и проверить конфиг; убедиться в отсутствии ресурсов с фиксированными именами; создать namespace и временный интерфейс; передать настройки через закрытый временный файл в `wg setconf`; перенести и переименовать интерфейс; назначить адреса, MTU и default routes; записать DNS.

Маршрут по умолчанию добавляется для каждого семейства IP из Address. Это не гарантирует возможность передачи: peer должен покрывать назначения через AllowedIPs, а сервер — маршрутизировать трафик. При исключении выполняется попытка удалить созданные ресурсы; аварийное завершение процесса и сбои очистки требуют диагностики.

`run`: проверить namespace и обычного пользователя; выполнить `ip netns exec … runuser …`. При вызове из sudo пользователь берётся из SUDO_USER.

`status`: проверить наличие namespace и показать `wg show arwg0`. Handshake не проверяется автоматически при `up`.

`down`: проверить PID; при наличии процессов отказать; иначе удалить namespace и собственный DNS-файл.

## Ресурсы и ограничения

- Namespace: `approute-vpn`, запись в `/run/netns/`.
- Интерфейс: `arwg0`; временное имя создаётся случайно.
- DNS: `/etc/netns/approute-vpn/resolv.conf`, применяется через `ip netns exec`.
- Одна сессия; нет блокировки от параллельных вызовов.
- Сетевая изоляция не является полной песочницей: локальные службы и Unix-сокеты хоста остаются отдельным каналом взаимодействия.
- GUI, Windows, SOCKS, импорт правил по PID и перенос запущенных процессов отсутствуют.
