# Решения

## 2026-10-22: Linux и WireGuard для MVP

Идея проекта — выборочный VPN для приложений. Первый вариант использует штатные Linux network namespaces и WireGuard: это позволяет проверить маршрутизацию без собственного перехватчика пакетов и драйвера. Windows WFP и сопоставление сокетов с PID не реализованы.

## Выбор приложения через запуск

Команда `run` создаёт процесс внутри VPN namespace. Его дочерние процессы наследуют сеть. Уже работающие приложения не перемещаются. Такой интерфейс ограничивает MVP, зато задаёт явную границу применения VPN.

## Сетевой интерфейс с сокетом в сети хоста

WireGuard создаётся и конфигурируется в сети хоста, затем интерфейс переносится в namespace. Зашифрованный транспорт использует исходную сеть. Основание: [документация WireGuard](https://www.wireguard.com/netns/).

## Конфигурация без выполнения команд

Поддерживается ограниченное подмножество конфигурации WireGuard. Hooks и неизвестные параметры отклоняются. DNS должен состоять из IP-адресов. Это исключает выполнение shell-команд из импортированного конфига.

## Одна сессия и обычный пользователь

Namespace и конечный интерфейс имеют фиксированные имена. `run` отказывается запускать приложения с UID 0. `down` требует сначала закрыть процессы в namespace. Поддержка нескольких профилей отложена.
